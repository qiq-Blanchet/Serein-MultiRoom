# M5 第二阶段：当前房间完整归档与恢复前校验

> 状态：2026-11-10，`feature/multi-room` 开发分支。此阶段新增的是**多房间专用**备份能力；原版 `main`、现有 VPS 数据及原版 `deploy/compose.yaml` 完全不动。已用独立合成房间、模拟 Docker 和 GitHub Actions 进行自动回归，**尚未做真实双房 VPS 联机验收**。

## Dashboard 操作

在原版「设置 → 旧库迁移」页新增折叠的「当前房间完整归档」。单房部署不出现这个区域。进入 `xiaogi-main` 时：

1. 「创建当前房间完整备份」：网页确认后，后台只停止小玑这一间 memory 容器，创建归档，再重新启动小玑；其他 AI 按原状态运行。**会有短暂的本房服务中断**，不是无停机热备份。
2. 「刷新备份清单」：只看小玑自己的 `rooms/<uuid>/backups` 目录。按时间、文件名展示大小，不列出其他房间。
3. 「校验／预览」：只读取归档，校验来源房间 UUID、可读房间 ID、Gateway 身份和每个文件 SHA-256；不会读取到其他房间，也不会向数据库写东西。
4. 「下载」：浏览器原生流式下载 `serein-xiaogi-main-<timestamp>-<random>.tar.gz`。只允许当前已登录、当前实际选中的房间下载；另一房间的路径请求会被拒绝。

原版「下载当前数据库备份」与 Scene/Event 分类 Markdown 导出仍保留；完整房间归档是**额外选择**，不替换原版导入导出。

## 备份内容

压缩包结构：

```text
manifest.json
payload/config/**        # 该房间部署配置，包括 MCP 工具规则
payload/data/**          # 该房间数据、SQLite、独立索引、附件/上传目录
payload/secrets/**       # 该房间内外部 API 身份和密钥（敏感！）
```

`manifest.json` 含归档格式版本、UTC 创建时间、来源房间内部 UUID / 可读房间 ID、镜像标识、SQLite user_version 与数据库结构 SHA-256 指纹、Gateway Key 的哈希、文件路径清单、大小与 SHA-256 校验和。不会加入任何其他房间的目录，也不会递归打包 `backups`，不会包括原版单房 VPS 或全局管理员账户。

压缩包是**含明文密钥的敏感文件**：存放在房间私有备份目录，磁盘权限限制为 0600；经 Dashboard 下载后须自行加密存储或放进可靠的私有备份位置，**不要上传公共 Git 仓库或分享公开下载链接**。这不是密钥脱敏的记忆导出 ZIP。

为避免 SQLite 活跃写入或 WAL 造成不一致，完整房间归档先停止对应房间，再用 **SQLite backup API** 生成一致性数据库副本，跳过已经纳入数据库快照的 WAL/SHM 临时侧车文件。配置、附件及其他普通文件在停止期间复制。符号链接、硬链接、特殊文件、路径遍历和不明归档成员会被拒绝。

## 安全保护

- **只认真实房间身份**：房间 UUID 从已签名网页房间选择中取得；额外的网页标签页房间头只用于检查是否切房，不能决定目标房间。下载 URL 中的房间 UUID 必须与当前选中房间一致。
- **不会静默串房**：若原先选择的房间已暂停/停止，网页不再自动掉到另一房间的数据库；出现明确的暂停提示和「选择其他可用房间」按钮，需要本人主动切换。
- **并发备份保护**：使用每个房间自己的非阻塞文件锁，防止两个网页标签页同时创建归档而互相提前重启房间。锁不跨房间，不会阻止 B 在 A 备份时继续运行。
- **只停止当前房间**：不停止其他房间，不移除 memory 容器的绑定目录；如果原本在运行，完成后尝试启动原房间并做健康检查。若备份或重新启动失败，管理接口报告失败；不能声称后台一定恢复成功。
- **备份校验不等于恢复**：归档预览会拒绝外房间归档和不匹配的 Gateway 身份；会逐文件验证 SHA-256，拒绝恶意路径与篡改内容。当前阶段没有数据库覆盖写入操作，`restore_available=false`。

## 网页无法打开时的独立应急命令

这不是日常创建/备份的必经步骤，仅供管理员在 VPS 维护时使用：

```bash
# 使用该安装已有的独立数据目录（不可指向原版正在使用的安装）
python3 scripts/rooms.py --root /srv/serein-multiroom-test backups <内部房间UUID>
python3 scripts/rooms.py --root /srv/serein-multiroom-test backup <内部房间UUID>
python3 scripts/rooms.py --root /srv/serein-multiroom-test backup-preview <内部房间UUID> <归档文件名>
```
